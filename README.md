# Kuzey Çağan Gebrecioğlu | Personal Portfolio & ESC Candidate Site

🌐 **Live:** [kuzeygeb.github.io](https://kuzeygeb.github.io)

Personal portfolio website showcasing international youth work, European Solidarity Corps (ESC) candidacy, Erasmus+ project experience, and academic research.

## Tech Stack

- [Astro](https://astro.build) v4 — Static Site Generator
- [TailwindCSS](https://tailwindcss.com) v3 — Utility-first CSS
- [DaisyUI](https://daisyui.com) v4 — Component library
- Custom EU-themed design system (`eu_theme` / `eu_dark`)

## Features

- 🇪🇺 EU-inspired design with custom DaisyUI themes
- 🌙 Dark / Light mode toggle
- 🇬🇧🇹🇷 Bilingual (English / Turkish) with client-side switching
- 📄 CV with timeline layout
- 📸 Interactive media gallery with filtering & lightbox
- ✍️ Blog with Markdown/MDX support & RSS feed
- 📊 SEO optimized (OG, Twitter Cards, JSON-LD, Sitemap)

## Development

```bash
npm install
npm run dev      # Start dev server
npm run build    # Production build
npm run preview  # Preview production build
```

## Deployment

Configured for GitHub Pages deployment at `https://kuzeygeb.github.io`.
